# MNIST Handwritten Digit Classification

A machine learning project for classifying handwritten digits from the MNIST dataset.

## Overview

This project uses the MNIST dataset to train machine learning models for handwritten digit classification.

The project includes data preprocessing, normalization of pixel values, model training, and evaluation.

## Project Workflow

1. Load the MNIST dataset
2. Preprocess the image data
3. Normalize pixel values
4. Train the classification model
5. Evaluate model performance
6. Analyze the predictions

## Technologies Used

- Python
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Dataset

The project uses the **MNIST handwritten digit dataset**, which contains grayscale images of handwritten digits from 0 to 9.
